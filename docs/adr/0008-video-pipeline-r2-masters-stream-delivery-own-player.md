# Video: R2 masters, Stream for delivery only, our own player and captions

Source masters are uploaded (resumable multipart) to a private R2 bucket and kept there as the Na iSema-controlled original; the Worker then asks Cloudflare Stream to copy each master from a short-lived signed R2 URL, and Stream's signed webhooks drive processing state. Playback uses a native `<video>` element with hls.js rather than Stream's iframe player, and captions are generated as WebVTT from our own reviewed Segments of the published Revision, never stored in Stream; Stream's automatic captions are off. We chose this because Stream's player cannot support synced transcripts, independent Fijian/English toggles, hidden-caption mode and word popovers well, captions stored in Stream would bypass review gates and revision history, and Stream is not an archive we control (VTECH-01/06). Changing video provider means pointing a new provider at the same R2 masters.
