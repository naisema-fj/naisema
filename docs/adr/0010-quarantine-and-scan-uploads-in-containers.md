# Quarantine every upload and scan it with ClamAV in Cloudflare Containers

The PRD requires uploaded files to be validated, scanned and restricted (TECH-02), and Cloudflare has no built-in malware scanning. Every upload lands in a private quarantine R2 bucket; a Queue message triggers a ClamAV scan running in Cloudflare Containers (generally available since April 2026), and only clean files are copied to their destination bucket. This keeps the all-Cloudflare decision (ADR-0004) and keeps unscanned bytes away from any public or processing path. We rejected sending files to an external scanning API because contributor and educator material is private, and rejected type-allowlisting alone because it does not detect malicious PDFs or media. ClamAV (GPL-2.0) runs as a separate container, not linked into the application.
